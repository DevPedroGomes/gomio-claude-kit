# Specifications

The normalized, implementation-ready version of the project requirements. The original source
material stays in `references/`.

Recommended structure:

```text
specs/
├── README.md
├── product.md
├── architecture.md
└── features/
    ├── feature-a.md
    └── feature-b.md
```

A feature specification defines:

- objective
- scope
- non-goals
- requirements
- constraints
- dependencies
- acceptance criteria
- verification
- open questions
