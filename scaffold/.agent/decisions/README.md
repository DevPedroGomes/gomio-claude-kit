# Architecture and Engineering Decisions

One file per decision: `NNNN-short-slug.md`, numbered in the order they were made. A single
growing `decisions.md` becomes unreadable within months and turns into the place decisions go to
be forgotten.

Record a decision when it materially affects architecture, dependencies, public contracts,
security, infrastructure, cost or maintainability.

Choosing to follow the dev guide is also a decision. Record it with the evidence that made it the
right call.

## Template

```markdown
# NNNN: <Decision>

- Date: YYYY-MM-DD
- Status: proposed | accepted | superseded by NNNN

## Context

What forced a decision? What constraints were real at the time?

## Decision

What was chosen, in one sentence.

## Alternatives

What else was considered, and what ruled each one out.

## Reason

Why this option won. Cite evidence: a benchmark, a doc, a cost, a constraint.

## Consequences

What this enables, what it rules out, and what will hurt later.
```
